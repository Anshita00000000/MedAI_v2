# MedAI — Clinical Intelligence Platform

MedAI converts doctor-patient conversations into structured medical records using AI-powered decision support.

## Features

- **ASR** — Multi-model transcription (Whisper local / API) with speaker diarisation
- **Cleaning** — Filler word removal, medical abbreviation expansion, PHI de-identification
- **Role classification** — MedPhi-Instruct few-shot classification (Doctor / Patient / Nurse / Family)
- **Clinical NER** — scispaCy + ClinicalBERT + GLiNER with UMLS linking
- **Negation detection** — medSpaCy/negspaCy for accurate symptom extraction
- **SOAP generation** — Section-specific prompts via MedGemma (fallback: Gemini 2.5 Flash)
- **DDx engine** — Columbia University KB lookup + LLM reranking
- **Risk stratification** — Urgency classification with RAG-grounded red flag detection
- **Treatment recommendations** — Evidence-based suggestions with medication details
- **Reports** — PDF (doctor + patient) via WeasyPrint, FHIR R4 JSON bundle
- **Evaluation** — WER/CER, NER precision/recall/F1, ROUGE + BERTScore for SOAP

## Setup

### 1. Clone and install

```bash
git clone https://github.com/anshita00000000/medai_v2.git
cd medai_v2
pip install -r medai/requirements.txt
```

### 2. Download NLP models

```bash
python -m spacy download en_core_web_sm
# Optional — for full NER:
pip install https://s3-us-west-2.amazonaws.com/ai2-s2-scispacy/releases/v0.5.4/en_core_sci_md-0.5.4.tar.gz
```

### 3. Configure environment variables

```bash
cp medai/.env.example .env
# Edit .env and fill in:
# GEMINI_API_KEY     — Required for Gemini fallback (recommended)
# HUGGINGFACE_TOKEN  — Required for MedGemma, MedPhi, pyannote
# OPENAI_API_KEY     — Required only for whisper_api backend
```

### 4. Build the Columbia Knowledge Base

```bash
cd medai
python knowledge/columbia_parser.py
# Output: data/knowledge_base/columbia_kb.json
# Prints: "Parsed N diseases, M unique symptoms"
```

### Full pipeline on a sample transcript

```python
from medai.pipeline.clean.text_cleaner import TranscriptCleaner
from medai.pipeline.intelligence.soap_generator import SOAPGenerator
from medai.pipeline.identify.ner import ClinicalNER
from medai.pipeline.intelligence.ddx_engine import DDxEngine
from medai.pipeline.intelligence.risk_stratifier import RiskStratifier
from medai.pipeline.intelligence.treatment import TreatmentRecommender

transcript = """
Doctor: What brings you in today?
Patient: I've had chest pain for three days. It gets worse when I breathe in deeply.
Doctor: Any shortness of breath or fever?
Patient: A little breathless, but no fever. I smoke about 10 cigarettes a day.
"""

cleaner = TranscriptCleaner()
cleaned = cleaner.clean(transcript, "prefixed")

soap_gen = SOAPGenerator()
soap = soap_gen.generate(cleaned)

ner = ClinicalNER()
ner_result = ner.extract(cleaned.cleaned_text)

ddx = DDxEngine().generate_ddx(ner_result, soap.assessment)
risk = RiskStratifier().stratify(ner_result, ddx, soap.assessment)
treatment = TreatmentRecommender().recommend(soap, ddx, risk)

print(soap.assessment)
print(f"Top DDx: {ddx.differentials[0].disease_name}")
print(f"Urgency: {risk.urgency}")
```

## Loading RAG Guidelines (NICE / WHO)

```python
from medai.knowledge.rag_pipeline import RAGPipeline

rag = RAGPipeline()
n = rag.load_guidelines("medai/data/knowledge_base/guidelines/")
print(f"Indexed {n} chunks")
```

Once loaded, `RiskStratifier(rag_pipeline=rag)` will automatically use retrieved chunks.

## Model Fallback Chain

All LLM calls follow this chain:

```
MedGemma (GPU required)
  → MedPhi for classification tasks
  → Gemini 2.5 Flash (API key required)
  → RuntimeError("No LLM available")
```

Set only `GEMINI_API_KEY` for a fully cloud-based deployment with no GPU required.

## Environment Variables

| Variable | Default | Description |
|---|---|---|
| `GEMINI_API_KEY` | — | Google Gemini API key (recommended) |
| `HUGGINGFACE_TOKEN` | — | HuggingFace token for MedGemma, MedPhi, pyannote |
| `OPENAI_API_KEY` | — | OpenAI key (whisper_api backend only) |
| `ASR_MODEL` | `whisper_local` | `whisper_local`, `whisper_api`, `medasr` |
| `WHISPER_MODEL_SIZE` | `base.en` | `tiny`, `base`, `small`, `medium`, `large` |
| `ROLE_CLASSIFIER_MODEL` | `medphi` | `medphi` or `gemini` |
| `PRIMARY_LLM` | `medgemma` | `medgemma` or `gemini` |
| `FALLBACK_LLM` | `gemini` | Fallback LLM |
